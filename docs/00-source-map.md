# Source map

Private notes. Original names live only in this file so the structure can be traced. Every other doc uses synthetic names. Do not put original names in UI, portraits, dialogue, or anything you might show someone else.

The source is a 2003 GBA episode TRPG: short scene, one isometric fight, then a workshop. It is not the action games in the same series.

## Structure that was copied

| Source idea | Replica |
|---|---|
| Linear world map, next episode locked | Same |
| Deploy a small squad, lead is mandatory | 8, including Kairo |
| Player phase, then enemy phase | Same. No speed bar |
| Move, then one action | Same |
| Weapon decides range | Sword / axe / fist / dagger = 1. Spear = 2. Bow / gun = line |
| Flat level, about 100 EXP | Same. No reclass |
| Body locked to a weapon family | Same |
| Items equipped before battle | Same |
| KO lasts one map. Lead death loses | Kairo, plus an optional story partner |
| Souls + stones + recipes, then enhance | Four stone ranks. +1 to +4 |
| Skill can live on the enhanced item | Same |
| Random counter stance, melee only, not on bosses | Declared stance. See deviations |
| Lead spends half max SP, AI controls a few turns | Oni-Wake. 2–3 enemy phases, then a dump turn |
| Grind tower, calendar barely moves, secret child | Hollow Depths, 12 floors, Soot-Child |
| Four beast camps, minister, scientist, unifier twice | Seat Beasts, Fox-Minister, Glass-Surgeon, Kurogane two skins |
| Most maps are routs. Some are “kill the named lord” | Same, plus one twin-revive map and one gun-nest map |

## Deviations (on purpose)

1. **Issen is declared, not rolled.** The original offers it at roughly 1 in 16, before the unit acts. You may only move, then set it. Any other action cancels it. Sword, spear, or axe only. The next physical strike is avoided and the attacker dies. Extra souls. Bosses are immune. If nobody strikes, nothing happens. The replica keeps the payoff and the “do nothing but move and set it” rule, and drops the dice so positioning is a choice.
2. **Allies can be passed through. Enemies cannot.** Whether the original allowed passing allies is unverified. The replica uses the familiar tactics rule.
3. **Height is three bands.** The original blocks attacks across an extreme height gap and makes slopes awkward. Exact costs are unverified. Replica: Low / Mid / High. Gap of 2 fails the attack. Crossing into the next band costs +1 move.
4. **Deploy cap 8.** Guides disagree. 8 is the working cap, Kairo included.
5. **Campaign is 24 fights plus a coda**, not 40-plus episodes. Same march, fewer repeated routs.
6. **No guardian or job system.** One stray summary described celestial guardians as classes. Equipment lists lock bodies to weapon families. That lock wins.
7. **Absolute Death is chanted for one turn** and hits a declared cluster, not a silent five-unit delete.
8. **Dagger counts as a short blade for Issen.** Original Issen was sword, spear, axe. Ninjas need the bait toy or they are only damage.
9. **Fox-Minister does not join.** A late extra sword with no job was cut. Roster stays at 17.
10. **Episode 9’s captain can be Issen’d.** Later lords cannot. The new counter needs a named target that is not immune.

Exact original deploy cap, ally pass-through, slope costs, and the full episode count. Do not “correct” the replica back toward those until a primary source is in hand.
